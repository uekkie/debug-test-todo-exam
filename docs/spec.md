# 仕様書：TODO アプリ

ログインしたユーザーが、自分の TODO を管理するアプリです。

## ログイン

- メールアドレスとパスワードでログインする
- ログインしていないと、TODO の画面は開けない

## TODO が持つ情報

| 項目 | 内容 |
|---|---|
| タイトル | 必須。50文字まで |
| カテゴリ | 任意（仕事・買い物・勉強、またはなし） |
| 締切 | 任意（日付） |
| メモ | 任意（複数行） |
| 完了 | 完了か未完了か。登録したときは未完了 |

## 一覧画面

1. 自分の TODO だけが表示される
2. 並び順は**締切が近い順**。締切のないものは最後
3. 上部に「未完了 N 件」を表示する。数えるのは**自分の**未完了の TODO
4. 「すべて」「未完了」「完了」で絞り込める
5. タイトルで検索できる（部分一致）。検索語にどんな文字を入れても、検索語を含まないものは出ない
6. 各行の左のボタンで、完了と未完了を切り替えられる。完了したものは ✔ が付き、灰色の取り消し線で表示する
7. 締切を過ぎていて未完了のものは、赤字で「期限切れ」と表示する。**締切が今日のものは、まだ期限切れではない**
8. カテゴリ名を表示する

## 詳細・登録・編集・削除

1. 詳細画面では、すべての項目を表示する。メモは改行を保って表示し、メモに HTML を書いても**文字としてそのまま表示**する
2. 登録・編集の画面で、タイトル・カテゴリ・締切・メモを入力できる。タイトルが空のときは保存せず、エラーを表示する
3. 編集して保存しても、**完了の状態は変わらない**
4. 削除すると一覧に戻り、「削除しました」と表示する
5. **他人の TODO は、見ることも、変えることも、消すこともできない**（存在しないものとして扱う）

## そのほか

- 一覧の表示が遅くならないこと。TODO の件数が増えても、データベースへの問い合わせ回数は増えない
