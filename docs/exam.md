# デバッグテスト：TODO アプリ

## やること

この TODO アプリには、[仕様書](spec.md) と違う動きをするバグが **12個** 埋め込まれています。
できるだけ多く見つけて、直してください。

- 制限時間：**120分**
- バグは、やさしいものから難しいものまで、段階的に入っています（やさしい4つ・ふつう4つ・むずかしい4つ）
- 1つ直すごとに、下の「回答シート」に書いてください

## ルール

- AI を使ってかまいません。ただし、**どのバグについても「どう見つけたか」「なぜそれが原因か」を自分の言葉で説明できること**が条件です。説明できないものは、見つけたことにしません
- 仕様書に書かれていることが正しい動きです。仕様書にないことは、バグではありません
- 直し方はひとつではありません。仕様どおりに動けば、どう直してもかまいません

## 準備

```bash
bin/setup
bin/rails db:seed
bin/rails server
```

- http://localhost:3000 を開き、`alice@example.com` / `password` でログインします
- 別のユーザーとして `bob@example.com` / `password` もあります
- サーバーのログ（`log/development.log`）も手がかりになります
